## Colab MLM Pretraining Fixes
- Diagnosed silent startup + low GPU utilization during MLM pretraining.
- Root causes:
  - FASTA loading had no progress output and fully loaded large genomes before first print.
  - Dataset defaulted to `num_samples=len(sequences)`, which is tiny for MLM and underutilizes GPU.
  - Relative config paths in Colab can resolve incorrectly when executed from different working dirs.
- Implemented fixes:
  - Added verbose FASTA progress logging and optional per-file base cap.
  - Added `samples_per_epoch`, `log_interval`, and `num_workers` to pretrain config/loader path.
  - Added explicit GPU/device startup logging in pretraining.
  - Resolved config paths relative to config file location.
  - Added tests for config parsing/path resolution and FASTA cap behavior.
