# Daily Log: 2026-02-01

## Issue: MLM Accuracy Stuck at 18%

### Problem
Model reached 18% MLM accuracy after 68 epochs and stopped improving.

### Investigation

1. **Created diagnostic script** (`diagnose_mlm_issue.py`)
   - Tests random baseline, masking, overfit capability, prediction analysis, gradient flow

2. **Key Findings**
   - Random baseline: 0.02% (1/4091 tokens)
   - Model CAN overfit on fixed batch: 100% accuracy
   - Model struggles on random DNA: ~1.5% after 10 epochs
   - Real DNA training: 18% (learning patterns!)
   - Architecture is NOT the problem

3. **Root Cause Analysis**
   - DNA has weaker contextual patterns than text
   - 18% might be close to optimal for DNA MLM with BPE
   - BUT: LR was too low (0.0001) for effective batch 2048
   - Linear scaling rule suggests LR should be ~0.0008

### Fixes Applied

1. **Config changes** (`config.yaml`):
   - `mlm_lr`: 0.0001 → 0.0005 (5x increase)
   - `mlm_weight_decay`: 0.05 → 0.01 (5x decrease)
   - `mlm_grad_accum_steps`: 16 → 4 (4x smaller effective batch)
   - `mlm_warmup_ratio`: 0.06 → 0.02 (3x faster warmup)
   - `mlm_final_lr_ratio`: 0.1 → 0.05

2. **Created diagnostic tools**:
   - `diagnose_mlm_issue.py` - comprehensive MLM diagnostic
   - `test_real_genome.py` - quick training test with real data

### Next Steps
1. Re-run MLM pretraining with new config
2. Monitor accuracy improvement over epochs
3. If still plateaus, consider:
   - Span masking instead of token masking
   - Different masking probability (20% instead of 15%)
   - More diverse genome data
