Add a “tiny transfer test” command (fast sanity run)

This prevents wasting hours on a broken “pretrain isn’t actually helping” pipeline.

Add a new script training/transfer_smoketest.py.

Behavior:
- Loads config.yaml
- Runs MLM pretrain for a tiny budget (e.g. 200-500 optimizer steps)
- Runs stage1 for a tiny budget (e.g. 1 epoch or 300 steps) twice:
   A) with pretrained encoder loaded
   B) from scratch
- Prints: stage1_mcc_pretrained, stage1_mcc_scratch, delta
Repeat for stage2 similarly (if stage2 script supports short runs).

Add config knobs:
- smoketest_steps_pretrain
- smoketest_steps_stage1
- smoketest_steps_stage2

CHECKPOINT:
- Run transfer_smoketest.py and verify delta is not ~0.000 every time.
If it is, print whether the encoder weights are actually changing the model outputs (e.g., compare first batch logits).
